🗄️ Administración de Base de Datos

⚠️ Zona de Peligro: Estas opciones realizan borrados masivos. Requieren la palabra clave BORRAR en mayúsculas para confirmarse. Estas acciones NO se pueden revertir.

1. Borrar todos los funcionarios (Sin borrar datos)

Elimina todo tu listado de funcionarios de la plataforma web. Tus registros históricos de días de permiso se conservarán en el servidor de la base de datos como respaldo, pero la plataforma web quedará vacía lista para el nuevo año.

2. Borrar todos los permisos (Sin borrar funcionarios)

Limpia todos los días administrativos de todos los funcionarios y los deja en cero (0/6). Conservará intacto tu listado de personal con sus RUTs y Nombres. Ideal para reiniciar los días a principio de año.

3. Borrar TODA la base de datos

Destrucción total. Borra a todos los funcionarios y elimina todo el historial de días administrativos, tanto de la web como del servidor de base de datos de forma permanente.
